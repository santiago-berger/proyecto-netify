# Tecnologías utilizadas

## General

- JavaScript (módulos ES)
- Node.js
- npm
- Git / GitHub

## Backend (`server/`)

- Express: API REST
- MySQL: base de datos
- Sequelize: ORM para modelos y relaciones
- mysql2: driver de MySQL
- jsonwebtoken: autenticación con JWT
- bcrypt: hash de contraseñas
- cookie-parser: lectura de la cookie con el token
- cors: comunicación con el cliente
- express-validator: validación de datos
- dotenv: variables de entorno

## Frontend (`client/`)

- React: interfaz con componentes
- Vite: servidor de desarrollo y build
- React Router DOM: navegación y rutas protegidas
- Axios: peticiones a la API
- Recharts: gráficos
- Lucide React: íconos
- Tesseract.js: lectura de comprobantes (OCR)
- CSS propio
- Google Fonts (Inter y Space Grotesk)
